# GenaWeb · Portfolio

Sitio web personal de GenaWeb, con información sobre servicios de desarrollo web, proyectos y formas de contacto.

## Neon Courier

El portfolio incluye **Neon Courier**, un minijuego arcade desarrollado con HTML5 Canvas y JavaScript.

Para acceder al juego:

- Desde la sección **Portfolio**, selecciona **Jugar ahora**.
- O abre directamente [`game.html`](game.html).

Usa `WASD` o las flechas del teclado para mover la nave, esquivar meteoritos y recoger paquetes.
